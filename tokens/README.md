# Token overview

| Token              | Role |
| ------------------ | ---- |
| **BAUM**           | Agent economy token. Launches on Robinhood Chain, paired with USDX. Backs the [Broker vault](../brokers/vault.md), gates [Broker levels](../points-and-levels/levels.md), and is the incentive token. |
| **STABLE**         | Membership token. Burned to [mint Brokers](../brokers/mint.md). Continues alongside BAUM. |
| **USDX / mUSDX**   | Stable's mortgage-backed stablecoin and its yield-bearing wrapper. USDX is what the Broker network is built to distribute. Baum fees are paid in USDX. |
| **Sub-DAO tokens** | One per [sub-DAO](../sub-daos/README.md), launched on Baum's launchpad, paired only with USDX. |

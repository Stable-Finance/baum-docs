# Glossary

| Term | Meaning |
| ---- | ------- |
| **Activation** | A one-time BAUM fee that lets a Baum instance operate a Broker's wallet. Resets when the Broker is sold. See [Activation](deed-deck/activation.md). |
| **Baum instance** | The copy of Baum that runs one Broker's wallet. |
| **BAUM** | Baum's token. Backs the vault, gates Levels 4–5, and pays incentives. See [BAUM](tokens/baum.md). |
| **bps** | Basis points. 1 bp = 0.01%, so 15 bps = 0.15%. |
| **Broker** | One card in the Deed Deck: an NFT with its own onchain wallet. |
| **DCA** | Dollar-cost averaging: buying a fixed amount on a schedule. |
| **Deed Deck** | The collection of 3,888 Broker playing cards. See [The Deed Deck](deed-deck/README.md). |
| **ERC-721** | The standard for NFTs on Ethereum-style chains. |
| **ERC-6551** | The standard that gives an NFT its own wallet (a "token-bound account"). |
| **FDV** | Fully diluted valuation: token price × total supply. |
| **Level** | A Broker's tier, 1 to 5. Higher levels mean more reward weight and lower fees. See [Levels](points-and-levels/levels.md). |
| **LP** | Liquidity provider, or providing liquidity to a trading pool. |
| **LP-out ladder** | How the treasury sells BAUM into the market at set FDV levels. See [Treasury LP-out ladder](tokens/treasury-lp-out-ladder.md). |
| **Launchpad** | Where sub-DAO tokens launch. |
| **Multiplier Attribute** | The one trait that affects earnings: it multiplies a Broker's points. See [Traits](deed-deck/traits.md#multiplier-attribute). |
| **mUSDX** | The yield-bearing version of USDX. |
| **Points** | What a Broker earns for putting capital to work. They set its level. See [Earning points](points-and-levels/README.md). |
| **Portal** | Where you fund a Broker and choose what Baum does. See [Portal overview](portal/README.md). |
| **Reward weight** | How much of the sub-DAO allocations a Broker gets, based on its level. |
| **Robinhood Chain** | The blockchain Baum and the Deed Deck run on. |
| **STABLE** | Stable's membership token. Used in the whitelist mint. |
| **Stock Tokens** | Tokenized stocks on Robinhood Chain. |
| **Sub-DAO** | One of five asset-class groups. Every Broker belongs to one. See [Sub-DAOs](sub-daos/README.md). |
| **Sunset rule** | Activation fees and lock requirements halve as BAUM's FDV grows. See [Sunset rule](points-and-levels/sunset-rule.md). |
| **TGE** | Token generation event: when a token launches. |
| **USDG** | A USD stablecoin. Lent in the [USDX lending market](lending-market.md). |
| **USDX** | Stable's mortgage-backed stablecoin. Baum's fees are paid in it. |
| **Vault** | Holds the BAUM reserve. Redeem a Broker for 50,000 BAUM, or buy one. See [Broker vault](deed-deck/vault.md). |

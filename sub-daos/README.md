# Sub-DAOs

There are five sub-DAOs. Each is an asset class, and every Broker belongs to exactly one — assigned at claim, at random and with equal weight (see [Sub-DAO membership](../deed-deck/traits.md#sub-dao-membership)).

Each sub-DAO launches its own token on the Baum launchpad. **Sub-DAO tokens pair only with USDX.**

## Token allocation

Per sub-DAO:

| Allocation                  | %   |
| --------------------------- | --- |
| LP / USDX                   | 40% |
| Baum treasury               | 20% |
| Brokers of that sub-DAO     | 20% |
| Brokers of all sub-DAOs     | 10% |
| That sub-DAO's treasury     | 10% |

Both Broker allocations **stream over 12 months**, recomputed each epoch by [reward weight](../points-and-levels/levels.md) and votes cast. The 10% cross-sub-DAO slice is weighted by reward weight and governance participation across the network. The Multiplier Attribute plays no part in either.

Each sub-DAO's LP bucket follows the same [LP-out ladder](../tokens/treasury-lp-out-ladder.md) as BAUM, funding its treasury as the token grows. The remaining 25% stays as standing USDX liquidity.

## Launch order

* **Stocks** launches first, in **October**.
* The second sub-DAO follows six to twelve weeks later.
* Then one every six to twelve weeks.

# Portal fees

For funded-wallet instances, Baum charges:

* **15 bps on volume**, and
* a **20% markup on API spend**.

Fees are charged in USDX. **No performance fee.**

Both fall with Broker level — the volume fee reaches 2 bps and the API markup reaches zero at Level 5:

| Level | Volume fee | API markup |
| ----- | ---------- | ---------- |
| 1     | 15 bps     | 20%        |
| 2     | 12 bps     | 15%        |
| 3     | 9 bps      | 10%        |
| 4     | 5 bps      | 5%         |
| 5     | 2 bps      | 0          |

See [Levels](../points-and-levels/levels.md) and [Fee routing](../tokens/fee-routing.md).
